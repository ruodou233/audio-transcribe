# audio-transcribe — 音频转文字全流程 Skill

## 这是什么

`audio-transcribe` 是给 Agent 使用的转写决策与执行指南：先判断是否已有可用文字稿，再分别确认输出要求、支出策略和验收强度，结合使用者自己的账户、本地算力与可用模型动态选择转写管线，最后按证据校对并验收结果。

它提供路径选择、执行约束和验收规则；具体 ASR 接口以及转换、对齐、校验脚本由执行 Agent 根据当前环境适配，因此它不是自带转写引擎的开箱即用应用。

## 适合与不适合

适合：

- 把录音、播客、会议或视频转成文字稿、逐字稿或字幕底稿。
- 需要说话人分离、时间戳、结构化导出或高风险字段核验。
- 比较本地与云端 ASR 的成本、准确性和隐私边界。
- 已有自动稿，但需要按原音频核验专名、数字、引语或否定词。

不适合：

- 只对已有文字稿做摘要、润色、改写或观点提炼。
- 绕过登录、付费、版权或访问控制获取第三方全文。
- 在没有音频或其他证据时，把听不清的内容补写完整。

## 三轴选择

| 选择轴 | 可选项 | 作用 |
|---|---|---|
| 输出要求 | 纯文本、说话人、段级/词级时间戳、SRT/VTT/JSON、热词 | 定义最终产物必须具备什么 |
| 支出策略 | 零新增 API 费、预算内平衡、精度优先 | 定义成本路线；精度优先仍需费用估算 |
| 验收强度 | 基础稿、校验稿、可发布稿 | 定义抽检、回听、双路与可追溯验收强度 |

“零新增 API 费”不等于完全没有成本：仍可能消耗现有免费额度、订阅配额或本机算力。Skill 不假定使用者拥有作者使用的飞书、阿里或 OpenAI 账户；具体候选按当前环境和当期官方资料复核。

## 实际依赖与降级方式

- 至少需要一条可用的云端 ASR 或本地管线；可发布稿默认需要两条实质独立的管线。
- 音频不可外传时只能使用已验证可用的本地能力；本地转写或必要的说话人分离能力不可用时，先提供本地能力补齐路线，用户拒绝或确实不可行时停止执行，不改用云端，也不宣称完成。
- 缺少关键能力时，Agent 会说明补齐收益与替代路线，请使用者选择安装、连接或登录，或接受明确标注质量差异的替代方案。
- 首次使用先按 [`local-config.example.md`](local-config.example.md) 探测本地模型、账户权益、认证和端点权限；候选发现规则见 [`references/asr-candidates.md`](references/asr-candidates.md)。

## 如何验证结果

详细规则见 [`SKILL.md` 的“第四步：校对”](SKILL.md#第四步校对按验收强度)。最小验收包含：

1. 输入文件的相对路径和哈希未发生意外变化。
2. 每个输入都有对应且非空的产物，不只比较文件总数。
3. 时间戳、行号和说话人结构通过程序化断言，修改可由原稿与终稿 diff 重建。
4. 人名、机构、数字、引语、否定词和低置信片段按证据抽检；长稿完成后扫描全局专名异写，批量或高风险任务再由未参与执行的一方独立抽样。

## 证据与限制

- [`SKILL.md` 的“案例注记”](SKILL.md#案例注记作者特定样本实测非通用基准)记录了作者在一个 3 小时双人中文访谈样本中的观察。它是作者案例记录，不是带公开原始样本和测量脚本的可复现基准，也不能外推为普遍准确率。
- 双 ASR 的价值是暴露分歧、减少把一致片段交给 LLM 重写的范围；它不能消除共同误识别或 LLM 错判，所以高风险字段仍需检索或回听。
- 跨项目 CER 排名、静态价格和新用户额度不作为默认选型依据；执行前按当前官方信息和任务样本重查。

## 安装

Claude Code：

```bash
mkdir -p ~/.claude/skills
git clone https://github.com/ruodou233/audio-transcribe.git ~/.claude/skills/audio-transcribe
```

Codex：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/ruodou233/audio-transcribe.git ~/.codex/skills/audio-transcribe
```

或通过 [agentops-skills](https://github.com/ruodou233/agentops-skills) 一次安装整套 Skill。已安装的仓库可在对应目录运行 `git pull --ff-only` 更新。

安装后可以直接说：“把这个播客转成带说话人和时间戳的校验稿，零新增 API 费优先。”
